It may invoke HackRF command-line tools such as `hackrf_transfer`, or use
HackRF-compatible APIs such as `libhackrf`, to configure transmit and receive
workflows.

HackRF is developed by Great Scott Gadgets:

https://github.com/greatscottgadgets/hackrf

HackRF tools, firmware, hardware designs, and libraries remain under their
respective upstream licenses. This repository does not include modified
HackRF GPL-covered source code.

Project-specific scripts, notes, reports, and experiment code in this
repository are licensed separately according to this repository's license
file, if one is present.

RF transmit experiments must be performed only in lawful conditions, such as
authorized frequencies, permitted power levels, suitable shielding, or other
controlled test environments required by local regulations.
